Isolation Rings & Enforcement — Four nested defense-in-depth boundaries. Each ring assumes the one inside it has already been compromised. The supervisor is in its own pod — never inside the sandbox.

Ring 1 — Agent Process

The openshell-sandbox parent process enforces Landlock filesystem restrictions, seccomp-BPF syscall filtering, and process identity checks. Irreversible after startup — the agent cannot override these controls.

Ring 2 — Sandbox Pod

Container or VM boundary. NetworkPolicy denies all egress except to the supervisor. Pod Security Standards, SELinux, and resource quotas bound what the sandbox can reach.

Ring 3 — Supervisor Pod

Separate pod (K8s), container (Docker/Podman), or host process (VM). Trusted policy engine, credential injection, DNS proxy, gateway session. Connected via mutual TLS.

Ring 4 — Hardware / VM

Kata Containers add a dedicated microVM kernel. Confidential Computing (SEV-SNP, TDX) extends trust into silicon. Hardware attestation verifies the sandbox runs the code it claims.

Inference Routing & Tool Governance — Three routing tiers (security → cost → efficiency) owned by different teams. Three nouns (skill, MCP server, service backend) with separate enforcement at each hop.

Tier 1 — Security

Lives client-side in every sandbox, inside the supervisor. Confidential context never leaves the cluster. Anything routed externally is PII-masked first.

Tier 2 — Cost

A lightweight classifier selects the cheapest model that can handle the request. Adds latency and can misroute — needs a fallback that escalates on low confidence.

Tier 3 — Efficiency

Once the model pool is fixed, llm-d endpoint picker maximizes KV-cache hits and balances load across vLLM workers.

Sandbox security is cheap

Enable it by default. Init adds 2.2% of E2E at C=1, under 5% at C=10. Full stack fits in 120mc / 242 MiB. The security benefits — per-binary policy, credential hiding, seccomp enforcement — far outweigh a cost that is barely measurable.

Benchmark the harness, not the model

Response processing (token classification, tool detection, stream forwarding) dominates latency: 498ms→2,437ms from C=1→C=10. GPU tensor cores are only 35% busy. Optimize the harness pipeline — you may not need more GPUs.

Every framework expands prompts 16–17× by injecting system instructions, tool schemas, and context. OTEL tracing decomposes the black box into measurable stages. Context assembly alone uses 1.34 cores avg (2.53 at P95).
